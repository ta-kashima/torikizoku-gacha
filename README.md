# 🍗 トリキガチャ (非公式ファンアプリ)

鳥貴族のメニューから、指定した品目数やPFC（タンパク質・脂質・炭水化物）の目標値に合わせてランダムにメニューを選出する、非公式のオーダー自動生成ツールです。

「今日は何を食べようか迷う」「減量中だけど、目標カロリー内でトリキを楽しみたい」という時に活用できるファンメイドの便利ツールです。

## ✨ 主な機能

* **ランダムオーダー生成:** 指定した品数のメニューをランダムに提案します。
* **PFC・カロリー計算:** 合計金額、総カロリー、PFCバランス、塩分相当量を自動計算・グラフ化します。
* **カスタマイズ設定:**
    * 目標カロリー・PFCの許容範囲指定（「筋トレ・減量」「糖質制限」などのプリセットあり）
    * 期間限定メニューの除外
    * 好きなメニューの固定（ピン留め）
    * 特定カテゴリーの必須/除外指定
* **シェア機能:** 決定したメニューを𝕏（旧Twitter）へシェア、またはクリップボードへコピーできます。

## 🚀 使い方

本アプリはフロントエンド（HTML/CSS/JavaScript）のみで動作する静的アプリケーションです。

1. 本リポジトリのURL（GitHub Pages）にアクセスするだけでブラウザ上で動作します。
2. ローカルで動かす場合は、リポジトリをダウンロードし `index.html` をブラウザで開いてください。
